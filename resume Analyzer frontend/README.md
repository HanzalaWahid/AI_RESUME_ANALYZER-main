# AI Resume Intelligence Platform - Frontend

A responsive, high-fidelity React-based dashboard UI for the AI Resume Intelligence Platform. Designed with a premium dark glassmorphic interface, interactive pipeline visualizers, radial score gauges, and deep-dive resume audit components.

## 🚀 Features

- **Upload & Parse**: Drag-and-drop workspace validating formats/file sizes and showing a simulated 6-stage parsing extraction pipeline.
- **ATS Dashboard**: Radial score gauge and sub-criteria progress meters, showing candidate strengths and flagged improvement accordions.
- **Resume Explorer**: Multi-tab panel dividing parsed resume entities into Profile Card, Work History, Education, and Skills Database Tag Clouds.
- **Semantic Job Matcher**: Direct job description inputs showing compatibility scores, missing keyword clouds, and priority action lists.
- **Skills Normalizer**: Dictionary lookup interface for adding/deleting raw technical terms and mapping them to standardized values.

## 🛠️ Technology Stack

- **Framework**: React 19 (Vite)
- **Icons**: Lucide React
- **Styles**: Custom Vanilla CSS & CSS Modules (Glassmorphism layout, fluid animations, custom scrollbars)

## 📦 Getting Started

### Installation

1. Install package dependencies:
   ```bash
   npm install
   ```

2. Run the development server:
   ```bash
   npm run dev
   ```

3. Compile the production bundles:
   ```bash
   npm run build
   ```

4. Preview the production compilation locally:
   ```bash
   npm run preview
   ```
